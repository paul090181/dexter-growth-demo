# Migration snapshots

These files are recovery/reference snapshots captured while beginning the GrowthWise Platform v1 reorganization.

- `automotive-v10/` contains the validated v10 upload-set files used for the Automotive lead gateway.
- `retail-dexters-current/index.html` contains the latest Dexter retail HTML available to the migration process.

These snapshots do not replace Git history, tags, releases, or the live repo. In particular, the Dexter snapshot may not contain every backend function used by its live deployment.
