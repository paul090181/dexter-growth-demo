# GrowthWise Core

Shared, industry-neutral capabilities belong here.

Initial candidates:
- AI assistant
- business/client context
- customers/leads abstraction
- media/photo handling
- publishing/campaign engine
- approvals
- analytics
- automation
- audit/activity history
- permissions

Rule: if a capability can reasonably serve Automotive and Retail, design it in Core first and place industry-specific fields/logic in adapters.
